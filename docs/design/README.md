# Design references

Approved mockups (desktop and mobile). Source of truth for layout, order, components and colour.
**Spacing and amount of text are compressed in all of them**: follow `docs/plans/phase-1-public-site.md`.

| File | Screen |
|---|---|
| `reference/home-desktop-approved.png` | Home, desktop |
| `reference/home-mobile-approved.png` | Home, mobile |
| `reference/technology-approved.png` | Tecnología, desktop + mobile |
| `reference/collaborate-approved.png` | Colabora, desktop + mobile |
| `reference/demo-entry-approved.png` | Demo entry (apps/web), desktop + mobile |

- Icons and illustrations: use the SVG files in `packages/ui/assets/`. Never cut images out
  of these mockups.
- The faces in the mockups are fictional. Never use them.
- The photos in the demo entry mockup are generated images: use them only if the team provides
  the original files with rights to use them.

Official NODES logos are SVG files kept by the team; add them to `packages/ui/assets/logo/`.

The texts in the mockups were drafts. The reviewed copy lives in `apps/site/src/i18n/*.json` and
`apps/web/src/i18n/demo-entry.*.json`.
